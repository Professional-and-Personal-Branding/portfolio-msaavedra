# 4.6 Rutas de las APIs de los ATS contra la documentacion oficial

Consultadas el 2026-11-12 (lectura de documentacion; no se llamo a ninguna API de terceros).

## Greenhouse — https://docs.greenhouse.io/job-board.html
- Confirmado: `GET https://boards-api.greenhouse.io/v1/boards/{board_token}/jobs/{job_id}`.
- Confirmado: `id`, `title`, `company_name` (presente en Retrieve a job, no en List jobs), `location.name`, `updated_at` (ISO 8601), `absolute_url`, `content` (HTML convertido a entidades HTML: hay que decodificarlo).
- NO confirmado: la variante EU (`boards-api.eu.greenhouse.io`, `boards.eu.greenhouse.io`). La documentacion solo menciona `boards-api.greenhouse.io`. Decision: `GreenhouseSource.canHandle` devuelve `false` para hosts `.eu.` y esa URL cae al respaldo JSON-LD (D3 lo preve); `matchAtsUrl` sigue reconociendo el host.

## Lever — https://github.com/lever/postings-api
- Confirmado: `GET https://api.lever.co/v0/postings/{site}/{id}` y la variante EU `https://api.eu.lever.co/v0/postings/{site}/{id}`.
- Confirmado: `text`, `categories` (`location`, `commitment`, `team`, `department`, `allLocations`), `workplaceType` (`unspecified`, `on-site`, `remote`, `hybrid`), `descriptionPlain`, `lists` (`text` + `content` HTML), `additionalPlain`, `applyUrl`.
- Forma supuesta: `createdAt` (ms) no figura en la pagina consultada. El fixture `lever-posting.json` lo marca; si falta, `postedAt` queda nulo.

## Ashby — https://developers.ashbyhq.com/docs/public-job-posting-api
- Confirmado: `GET https://api.ashbyhq.com/posting-api/job-board/{JOB_BOARD_NAME}` con `?includeCompensation=true`.
- Confirmado: `title`, `location`, `employmentType` (`FullTime`, `PartTime`, `Intern`, `Contract`, `Temporary`), `workplaceType` (`OnSite`, `Remote`, `Hybrid`), `isRemote`, `descriptionPlain`, `applyUrl`, `publishedAt`, `compensation.compensationTierSummary` (la doc es inconsistente sobre si `compensation` esta por vacante o en el nivel superior: la fuente lee `jobs[].compensation`).
- Forma supuesta: el campo `id` de cada vacante no esta documentado en la pagina. El fixture `ashby-board.json` lo marca; sin `id` en la respuesta real, la vacante no se encontraria (422 «Pegá el texto»), sin dano.
