Instrucciones para el owner (Migration Plan, paso 3 de design.md), cuando quiera reclasificar su base local:

  1. Aplicar la migración: `npm run prisma:migrate` desde `backend/` (no cambia ningún número: las filas previas quedan HUMAN).
  2. Simulación, sin escribir: `npm run views:reclassify`. Revisar el informe: cuántas filas pasan a BOT y el `views` actual -> nuevo de cada perfil.
  3. Respaldo: el `pg_dump` sin contraseña que sugiere el propio informe.
  4. Si el informe cierra: `npm run views:reclassify -- --apply`. Es idempotente: una segunda corrida no informa cambios.
