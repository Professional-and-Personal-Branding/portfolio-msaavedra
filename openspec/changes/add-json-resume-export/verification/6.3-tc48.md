## Observación (fuera de alcance de este change)

`frontend/Caddyfile` agrega `Cache-Control: no-cache` a todo lo que no sea `/assets/*` o `/fonts/*` (`@noCache`), también a `/api/*`. Por el contenedor `web`, la exportación de un perfil `PROTECTED` y la del panel llegan con dos líneas de `Cache-Control` (`no-cache` y `private, no-store`); `no-store` sigue presente. Directo contra la API la cabecera es la del diseño (D6). El detalle `GET /api/curated-profiles/:slug` tiene el mismo comportamiento previo. Decidir si `/api/*` sale de `@noCache` es un cambio de borde (queda para el owner).
